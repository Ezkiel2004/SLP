Tabs

Use tabs to switch between views of one topic. Keep labels short.

Overview

Tabs show one view of a topic at a time, such as a program's overview, who can apply and how to apply. The selected tab has a tint, a green ring and bold text.

When to use

Use tabs when readers switch between views of the same thing. For questions that readers open one at a time, use the accordion instead.

Accessibility

Only the selected tab is in the Tab order. Left and Right arrows move between tabs, Home and End jump to the first and last, and Tab moves into the panel. The Archived tab is unavailable, so the keyboard skips it.

Accordion

Use for FAQs. Readers open only what they need. No script is needed.

Which files does a page need?

Load css/tokens.css, css/base.css and css/components.css in that order. Add js/ui.js with defer when the page has a menu, tabs or a dialog.

How do I add an icon?

Copy the icon's paths from Lucide into a new symbol in img/icons.svg, then show it with an svg and use element. Always place it next to visible text.

Why does the accordion have no script?

It is a native details element. It works before scripts load, with the keyboard and with screen readers, and the browser's find-in-page opens it.

Can I add another color or font?

No. The brand is green and white with one font, Inter. Status colors are only for feedback messages.
