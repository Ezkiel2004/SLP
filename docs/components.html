SLP Information System — component library

Every component in the app, with all of its states. This page loads css/tokens.css, css/style.css and js/script.js directly, so it always matches production. Rules and rationale live in docs/DESIGN-SYSTEM.md.

Colour

One brand colour (SLP green), a neutral gray scale, and four status colours. Status colours are never decorative and never used without an icon and text.

Typography — Inter only

Six sizes, three weights. Body text is 16px; nothing a user must read is smaller than 14px. 12px is for badges' neighbours and metadata only.

32 / 40 Semibold — Sign in, stat values

24 / 32 Semibold — Page title (h1)

20 / 28 Semibold — Card and section heading (h2)

16 / 24 Semibold — Sub-heading (h3)

16 / 24 Regular — Body text, inputs, buttons (medium). Plain words, short sentences.

14 / 20 Regular — Table text, hints, descriptions, labels in toolbars.

12 / 16 — Captions and counts only.

Spacing and grid

8px scale (4px half-step for icon gaps). 12-column grid, 24px gutter. Page margins 16 → 24 → 32px at 600 / 1200px. Card padding 24px (16px on phones).

Buttons

44px tall, 16px medium text, 4px radius. One primary button per view area. Icon + label for primary actions; icon-only buttons need aria-label and title.

Do

Start labels with a verb: "Add beneficiary", "Send notification", "Confirm and save".

Don't

Use "+ Add New", "Submit", "OK", ALL CAPS, or two primary buttons side by side.

Form fields

Visible label above every control (never placeholder-only). Hint between label and control. Errors below the control as icon + text. Mark required fields "(required)".
